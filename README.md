# 🎨 ColorPaletteCLI

A tiny Python CLI tool that generates random color palettes for UI/UX projects.

## Features

- Generate random HEX colors
- Create palettes of any size
- Lightweight and beginner-friendly

## Run

```bash
python main.py
```

## Example

```
How many colors? 5

1. #3B82F6
2. #10B981
3. #F59E0B
4. #EF4444
5. #8B5CF6
```
